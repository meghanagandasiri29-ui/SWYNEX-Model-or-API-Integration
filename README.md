
# SWYNEX Model or API Integration

## Project: AI Text Summarizer

This project uses a locally running AI model to summarize long text into shorter, meaningful summaries.

## Features
- Enter text using a simple Streamlit interface.
- Generate summaries using a pretrained AI model.
- Display the generated summary.
- Handle missing input and errors.
- Run locally without an API key.

## Technologies Used
- Python
- Streamlit
- Transformers
- PyTorch
- DistilBART CNN model

## Installation

Install the required packages:

```bash
python -m pip install -r requirements.txt
```

## Run the Application

Start the application:

```bash
python -m streamlit run app.py
```

The pretrained model is downloaded automatically the first time the application runs.

## Example

Input: A long article or paragraph about Artificial Intelligence.

Output: A shorter summary generated by the local AI model.

## Security
No API keys or passwords are required.
